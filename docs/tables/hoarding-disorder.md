# 3.6.3 — Hoarding Disorder

**Hoarding Disorder:** Persistent difficulty discarding possessions due to a perceived need to save, resulting in clutter that compromises living areas.

| Consider and rule out | How it is distinguished from Hoarding Disorder |
| --- | --- |
| [Obsessive-Compulsive Disorder](3-6-1.md) | Accumulation results from obsessions (e.g., contamination) and is unwanted, not driven by a desire to save. |
| [Major Depressive Disorder](3-4-1.md) | Clutter reflects psychomotor slowing/amotivation rather than saving urges. |
| [Neurocognitive Disorder](3-16-2.md) | Accumulation stems from cognitive decline. |
| [Autism Spectrum Disorder / Psychotic disorders](3-1-3.md) | Collecting is tied to restricted interests or delusional beliefs. |
| Normal collecting | Organized, valued collections without clutter or impairment. |
