# 3.17.1 — Paranoid Personality Disorder

**Paranoid Personality Disorder:** Pervasive distrust and suspiciousness such that others' motives are interpreted as malevolent, beginning by early adulthood.

| Consider and rule out | How it is distinguished from Paranoid Personality Disorder |
| --- | --- |
| [Delusional Disorder, persecutory type](3-2-3.md) | Involves fixed delusions rather than pervasive but non-delusional suspiciousness. |
| [Schizophrenia](3-2-1.md) | Includes frank psychotic symptoms. |
| [Schizotypal Personality Disorder](3-17-3.md) | Adds cognitive-perceptual distortions and eccentricity. |
| [Schizoid Personality Disorder](3-17-2.md) | Detachment without prominent suspiciousness. |
| [Personality change due to another medical condition / substance-related](3-17-11.md) | Suspiciousness is attributable to a medical condition or substance. |

_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
