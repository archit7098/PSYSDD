# 3.17.4 — Antisocial Personality Disorder

**Antisocial Personality Disorder:** A pervasive pattern of disregard for and violation of others' rights since age 15, in an individual ≥18 with evidence of conduct disorder before age 15.

| Consider and rule out | How it is distinguished from Antisocial Personality Disorder |
| --- | --- |
| [Conduct Disorder](3-14-3.md) | The youth (<18) precursor; antisocial personality disorder requires age ≥18. |
| [Substance Use Disorders](3-15-1.md) | Antisocial acts occur only in service of substance use, without a lifelong pattern (may co-occur). |
| [Narcissistic Personality Disorder](3-17-7.md) | Exploitation without the impulsivity, aggression, and deceit for personal gain seen in antisocial. |
| [Manic Episode](3-3-1.md) | Irresponsible/antisocial behavior occurs only during mood elevation. |
| Criminal behavior without personality disorder | Illegal acts occur without the pervasive personality pattern. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
