# 3.13.1 — Gender Dysphoria

**Gender Dysphoria:** Marked incongruence between one's experienced/expressed gender and assigned gender, with clinically significant distress or impairment.

| Consider and rule out | How it is distinguished from Gender Dysphoria |
| --- | --- |
| Nonconformity to gender roles | Gender-atypical behavior without the marked incongruence and distress required for the diagnosis. |
| [Body Dysmorphic Disorder](3-6-2.md) | Preoccupation is with a perceived appearance defect rather than gender incongruence. |
| [Transvestic Disorder](3-18-1.md) | Cross-dressing is for sexual arousal without a desire to be the other gender. |
| [Psychotic disorders](3-2-1.md) | Any belief about being another gender is delusional rather than an identity experience. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
