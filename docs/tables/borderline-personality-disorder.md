# 3.17.5 — Borderline Personality Disorder

**Borderline Personality Disorder:** A pervasive pattern of instability in interpersonal relationships, self-image, and affect, with marked impulsivity.

| Consider and rule out | How it is distinguished from Borderline Personality Disorder |
| --- | --- |
| [Bipolar II / Cyclothymic Disorder](3-3-2.md) | Mood shifts are sustained episodes with increased energy/decreased sleep, versus brief reactive shifts. |
| [Depressive Disorders](3-4-1.md) | Chronic emptiness/instability is a personality trait rather than a discrete episode. |
| [Histrionic Personality Disorder](3-17-6.md) | Attention-seeking without the self-destructiveness, emptiness, and rage of borderline. |
| [Narcissistic Personality Disorder](3-17-7.md) | Self-image is grandiose and stable rather than unstable. |
| [PTSD / Complex trauma](3-7-1.md) | Instability is tied to trauma reexperiencing rather than a pervasive personality pattern. |
| [Substance-Induced changes](3-15-1.md) | Impulsivity/instability occur only during substance use. |
