# 3.6.5 — Excoriation (Skin-Picking) Disorder

**Excoriation Disorder:** Recurrent skin picking causing lesions, with repeated attempts to stop.

| Consider and rule out | How it is distinguished from Excoriation Disorder |
| --- | --- |
| [Obsessive-Compulsive Disorder](3-6-1.md) | Picking is not driven by an obsession. |
| [Body Dysmorphic Disorder](3-6-2.md) | Picking is to improve a perceived appearance defect. |
| Non-Suicidal Self-Injury | Intent is to relieve negative feelings via self-harm rather than habitual picking. |
| [Psychotic disorder (e.g., delusional parasitosis)](3-2-3.md) | Picking responds to a delusion of infestation. |
| Substance-induced (e.g., stimulants) | Picking occurs during stimulant use (formication). |
| Dermatological condition | Skin lesions are due to a primary dermatologic disorder. |
