# 3.18.1 — Paraphilic Disorders

**Paraphilic Disorders:** Recurrent, intense atypical sexual interests causing distress/impairment or entailing harm/risk to others (or nonconsenting persons).

| Consider and rule out | How it is distinguished from Paraphilic Disorders |
| --- | --- |
| Nonpathological atypical sexual interest | The interest does not cause distress/impairment or harm to others, so no disorder is diagnosed. |
| [Manic Episode / Substance Intoxication](3-3-1.md) | Hypersexual or atypical behavior occurs only during mood elevation or intoxication. |
| [Neurocognitive Disorder](3-16-2.md) | Disinhibited sexual behavior results from cognitive decline. |
| [Obsessive-Compulsive Disorder](3-6-1.md) | Sexual intrusive thoughts are ego-dystonic obsessions, not paraphilic arousal. |
| [Conduct Disorder / Antisocial Personality Disorder](3-17-4.md) | Sexual offenses occur within a broader antisocial pattern rather than a specific paraphilic interest. |
