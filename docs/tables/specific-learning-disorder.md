# 3.1.5 — Specific Learning Disorder

**Specific Learning Disorder:** Persistent difficulties learning and using academic skills (reading, writing, or mathematics) below expectation for age, not explained by other conditions.

| Consider and rule out | How it is distinguished from Specific Learning Disorder |
| --- | --- |
| [Intellectual Disability](3-1-1.md) | Academic difficulties are part of global intellectual and adaptive impairment. |
| Normal academic variation / lack of instruction | Underperformance is due to inadequate instruction, absence, or environmental factors rather than a learning disorder. |
| [Neurocognitive Disorder](3-16-2.md) | Represents a decline from previously attained academic skills rather than a developmental difficulty acquiring them. |
| [ADHD](3-1-4.md) | Poor academic performance stems from inattention; may co-occur with specific learning disorder. |
| Sensory impairment (vision/hearing) | Learning difficulty is attributable to an uncorrected sensory deficit. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
