# 3.6.1 — Obsessive-Compulsive Disorder

**Obsessive-Compulsive Disorder:** Recurrent obsessions and/or compulsions that are time-consuming or cause significant distress/impairment.

| Consider and rule out | How it is distinguished from Obsessive-Compulsive Disorder |
| --- | --- |
| [Generalized Anxiety Disorder](3-5-7.md) | Excessive worry about real-life concerns rather than intrusive, ego-dystonic obsessions with rituals. |
| [Body Dysmorphic Disorder](3-6-2.md) | Preoccupations and rituals focus specifically on perceived appearance defects. |
| [Hoarding Disorder](3-6-3.md) | Difficulty discarding driven by perceived need to save, not by obsessions. |
| [Trichotillomania / Excoriation](3-6-4.md) | Body-focused repetitive behaviors without preceding obsessions. |
| [Illness Anxiety Disorder](3-9-2.md) | Preoccupation is specifically about having an illness. |
| [Tic Disorders](3-1-6.md) | Tics are not preceded by an obsession and are less purposeful. |
| [Psychotic disorders](3-2-1.md) | OCD retains at least some insight in most cases; delusional disorder involves fixed non-ritualized beliefs. |
| [Obsessive-Compulsive Personality Disorder](3-17-10.md) | Pervasive perfectionism/control as ego-syntonic traits without true obsessions/compulsions. |
