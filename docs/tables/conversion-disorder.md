# 3.9.3 — Conversion Disorder (Functional Neurological Symptom Disorder)

**Conversion Disorder:** Altered voluntary motor or sensory function with clinical findings incompatible with recognized neurological/medical conditions.

| Consider and rule out | How it is distinguished from Conversion Disorder |
| --- | --- |
| Neurological disease | Examination shows findings compatible with a recognized neurological disorder. |
| [Somatic Symptom Disorder](3-9-1.md) | Symptoms are not specifically neurological or incompatibility is not demonstrable. |
| [Factitious Disorder / Malingering](3-9-5.md) | Symptoms are intentionally produced (for the sick role or external incentive). |
| [Dissociative Disorders](3-8-1.md) | Symptoms are dissociative (memory/identity) rather than sensorimotor. |
| [Panic Disorder](3-5-5.md) | Neurological-seeming symptoms occur only during panic attacks. |
