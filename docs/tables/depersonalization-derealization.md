# 3.8.2 — Depersonalization/Derealization Disorder

**Depersonalization/Derealization Disorder:** Persistent/recurrent experiences of detachment from one's self (depersonalization) or surroundings (derealization) with intact reality testing.

| Consider and rule out | How it is distinguished from Depersonalization/Derealization Disorder |
| --- | --- |
| [Panic Disorder / Anxiety Disorders](3-5-5.md) | Depersonalization occurs only during panic attacks or anxiety episodes. |
| [PTSD / Acute Stress Disorder](3-7-1.md) | Dissociation is part of the trauma-related symptom picture. |
| [Psychotic Disorders](3-2-1.md) | In psychosis, reality testing is lost; here the individual knows the experience is not real. |
| Substance-Induced / Medical | Symptoms are attributable to a substance (e.g., cannabis, hallucinogens) or medical condition (e.g., seizures). |
| [Major Depressive Disorder](3-4-1.md) | Detachment occurs only within a depressive episode. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
