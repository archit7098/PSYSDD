# 3.17.7 — Narcissistic Personality Disorder

**Narcissistic Personality Disorder:** A pervasive pattern of grandiosity, need for admiration, and lack of empathy.

| Consider and rule out | How it is distinguished from Narcissistic Personality Disorder |
| --- | --- |
| [Antisocial Personality Disorder](3-17-4.md) | Exploitation is accompanied by impulsivity, aggression, and deceit for material gain. |
| [Histrionic Personality Disorder](3-17-6.md) | Attention seeking is for nurturance rather than to confirm superiority. |
| [Borderline Personality Disorder](3-17-5.md) | Self-image is unstable rather than grandiose. |
| [Manic Episode](3-3-1.md) | Grandiosity is episodic and accompanied by mood/energy change. |
| [Obsessive-Compulsive Personality Disorder](3-17-10.md) | Preoccupation with order/perfectionism rather than admiration and grandiosity. |
