# 3.17.6 — Histrionic Personality Disorder

**Histrionic Personality Disorder:** A pervasive pattern of excessive emotionality and attention seeking.

| Consider and rule out | How it is distinguished from Histrionic Personality Disorder |
| --- | --- |
| [Borderline Personality Disorder](3-17-5.md) | Adds self-destructiveness, chronic emptiness, and identity disturbance. |
| [Narcissistic Personality Disorder](3-17-7.md) | Attention seeking is to affirm superiority rather than for nurturance. |
| [Dependent Personality Disorder](3-17-9.md) | Reliance on others without the dramatic, seductive attention seeking. |
| [Somatic Symptom Disorder](3-9-1.md) | Focus is on physical symptoms rather than dramatic interpersonal style. |
