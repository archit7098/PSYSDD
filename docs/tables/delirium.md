# 3.16.1 — Delirium

**Delirium:** An acute, fluctuating disturbance of attention and awareness with an additional cognitive disturbance, developing over hours to days from a medical cause, substance, or multiple etiologies.

| Consider and rule out | How it is distinguished from Delirium |
| --- | --- |
| [Major/Mild Neurocognitive Disorder](3-16-2.md) | Chronic, stable cognitive decline with preserved attention/awareness (though delirium can be superimposed). |
| [Psychotic Disorders](3-2-1.md) | Consciousness/attention are intact and onset is not acute-fluctuating. |
| [Acute stress / dissociative states](3-8-2.md) | No global attentional disturbance with a medical/substance cause. |
| [Major Depressive Disorder (with poor concentration)](3-4-1.md) | Attention/awareness are not acutely and globally impaired with fluctuation. |
