# 3.9.2 — Illness Anxiety Disorder

**Illness Anxiety Disorder:** Preoccupation with having/acquiring a serious illness, with minimal somatic symptoms and high health-related anxiety.

| Consider and rule out | How it is distinguished from Illness Anxiety Disorder |
| --- | --- |
| [Somatic Symptom Disorder](3-9-1.md) | Prominent distressing somatic symptoms are present. |
| [Generalized Anxiety Disorder](3-5-7.md) | Worry spans many topics, not just illness. |
| [Obsessive-Compulsive Disorder](3-6-1.md) | Illness-related intrusive thoughts are obsessions with associated compulsions across other themes. |
| [Major Depressive Disorder](3-4-1.md) | Health preoccupation occurs only within a depressive episode. |
| [Delusional Disorder, somatic type](3-2-3.md) | The illness belief is held with delusional conviction. |
| Adjustment reaction to real medical illness | Anxiety is a proportionate response to a genuine, serious diagnosis. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
