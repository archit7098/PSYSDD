# 3.10.4 — Binge-Eating Disorder

**Binge-Eating Disorder:** Recurrent binge eating with marked distress, without the regular compensatory behaviors of bulimia nervosa.

| Consider and rule out | How it is distinguished from Binge-Eating Disorder |
| --- | --- |
| [Bulimia Nervosa](3-10-3.md) | Regular inappropriate compensatory behaviors are present. |
| Obesity (without binge eating) | Overeating occurs without discrete binge episodes with loss of control. |
| [Major Depressive Disorder](3-4-1.md) | Increased appetite without discrete binges with loss of control. |
| [Bipolar Disorder](3-3-1.md) | Overeating occurs within mood episodes. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
