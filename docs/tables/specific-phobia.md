# 3.5.3 — Specific Phobia

**Specific Phobia:** Marked fear/anxiety about a specific object or situation, actively avoided, out of proportion to actual danger.

| Consider and rule out | How it is distinguished from Specific Phobia |
| --- | --- |
| [Agoraphobia](3-5-6.md) | Fear spans multiple situations centered on escape/help difficulty rather than one circumscribed object. |
| [Social Anxiety Disorder](3-5-4.md) | Fear is of social scrutiny. |
| [Separation Anxiety Disorder](3-5-1.md) | Avoidance relates to separation from attachment figures. |
| [PTSD](3-7-1.md) | Avoidance is of trauma reminders. |
| [Obsessive-Compulsive Disorder](3-6-1.md) | Avoidance is driven by obsessions (e.g., contamination). |
| [Panic Disorder](3-5-5.md) | Panic attacks are unexpected rather than cued only by a specific phobic stimulus. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
