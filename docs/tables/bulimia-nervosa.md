# 3.10.3 — Bulimia Nervosa

**Bulimia Nervosa:** Recurrent binge eating with inappropriate compensatory behaviors, ≥once weekly for 3 months, with self-evaluation unduly influenced by shape/weight.

| Consider and rule out | How it is distinguished from Bulimia Nervosa |
| --- | --- |
| [Anorexia Nervosa, binge-eating/purging type](3-10-2.md) | The individual is at significantly low weight; anorexia takes precedence. |
| [Binge-Eating Disorder](3-10-4.md) | Binges occur without regular compensatory behaviors. |
| [Major Depressive Disorder with atypical features](3-4-1.md) | Overeating occurs without binge loss-of-control or compensation. |
| Kleptomania / impulse-control disorders | Impulsivity is not centered on binge eating. |
| Medical causes of overeating (e.g., Kleine-Levin) | Hyperphagia is attributable to a neurological/medical syndrome. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
