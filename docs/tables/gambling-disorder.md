# 3.15.2 — Gambling Disorder

**Gambling Disorder:** Persistent, recurrent problematic gambling leading to clinically significant impairment or distress.

| Consider and rule out | How it is distinguished from Gambling Disorder |
| --- | --- |
| Professional/social gambling | Gambling is disciplined, limited, and not associated with loss of control or impairment. |
| [Manic Episode](3-3-1.md) | Excessive gambling occurs only during mood elevation. |
| [Antisocial Personality Disorder](3-17-4.md) | Gambling is part of a broader antisocial pattern (may co-occur). |
| [Substance Use Disorders](3-15-1.md) | Shares addictive features but involves substance ingestion. |

---
_Distinctions summarize differentiating features only. Confirm the full DSM-5 criteria for each disorder considered._
