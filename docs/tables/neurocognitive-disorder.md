# 3.16.2 — Major or Mild Neurocognitive Disorder

**Major/Mild Neurocognitive Disorder:** Acquired decline from a previous level in ≥1 cognitive domain; major NCD interferes with independence, mild NCD does not.

| Consider and rule out | How it is distinguished from Major/Mild Neurocognitive Disorder |
| --- | --- |
| [Delirium](3-16-1.md) | Acute, fluctuating attentional disturbance rather than a stable decline. |
| [Intellectual Disability](3-1-1.md) | Deficits are developmental and lifelong, not an acquired decline. |
| [Major Depressive Disorder (pseudodementia)](3-4-1.md) | Cognitive complaints improve with treatment of the depressive episode. |
| Normal aging | Age-expected cognitive change without significant decline or impairment. |
| Substance/Medication-Induced Neurocognitive Disorder | Decline is attributable to a substance/medication. |
| [Schizophrenia](3-2-1.md) | Cognitive impairment occurs within a primary psychotic illness. |
